# LJK Scanner - MTs Nurul Fata
Pemindai lembar jawaban pilihan ganda (OMR) yang berjalan di browser HP/laptop. Data nilai hanya tersimpan di perangkat masing-masing guru, tidak dikirim ke server.

- Buka alamat GitHub Pages repo ini, lalu "Tambahkan ke layar utama" supaya terpasang seperti aplikasi dan bisa dipakai offline.
- Cetak `LJK_MTs_Nurul_Fata_v2.pdf` di kertas A4 dengan skala 100% (jangan "fit to page").
- Untuk memperbarui aplikasi: ganti file `index.html` di repo ini. Jangan mengganti nama repo (data guru terikat ke alamatnya).
